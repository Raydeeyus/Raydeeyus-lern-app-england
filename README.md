# Klausuren

Lern-App (PWA) für alle Klausurfächer. Fächer-Ordner (Geschichte, Kunst, Sport), jeweils mit Unterricht und Klausurvorbereitung. Geschichte · Unterricht: England 1509–1714 mit Zeitstrahl (mit Herrscherwechseln: warum an die Macht, warum Ende), Lexikon, Karteikarten und Jahreszahlen-Quiz. Funktioniert offline.
